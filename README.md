A short video for make.fun's "Day one, day seven" bounty: the same tiny agent-built game — Vice Bay, a GTA-like open-world game built by an AI agent — on the day it was made and after a week of daily updates. Day 1 is the plain first build; day 7 is the same map and start, now with a storm, a police chase, traffic and five districts. The camera never moves — the change is the story.

The video was made and rendered in the agent session that built this entry (ffmpeg, from real gameplay footage of both builds), ends with make.fun's referral end card carrying the entrant's referral code, and was posted publicly on TikTok from @tentangblockchain. Its address is in VIDEO.json.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

## The video

The clip is 13 seconds, vertical 1080x1920. Its footage is real gameplay of Vice Bay recorded in this session: day 1 is the first build (commit `16b9c27`), day 7 is the latest build (commit `d41900d`), both staged the same way so the camera never moves. It ends with make.fun's referral end card from the press pack, with the entrant's referral code typed into its field.
